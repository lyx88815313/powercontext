# 验证样例：TASK-001 订单列表查询的状态筛选与金额下界筛选

> 对应任务定义文件：`minimax/demo/tasks/TASK-001-status-filter.md`
> 业务工程：`minimax/demo/`（fulfillment-svc，纯标准库 + pytest）

---

## 1. 任务描述

在 `fulfillment-svc` 中实现 `fulfillment.query.list_orders` 的**订单状态筛选**与
**金额下界筛选**，使实现符合规格 `SPEC-ORDER-QUERY`：

| 要求 | 来源规格 |
| --- | --- |
| `status` 为 `None` 时不过滤，返回全部订单 | SPEC-ORDER-QUERY-01 |
| `status` 非空时只返回状态匹配的订单 | SPEC-ORDER-QUERY-01 |
| `status` 不在允许集合 `{PAID, SHIPPED, CANCELLED, REFUNDED}` 时必须抛 `InvalidFilterError`（不得静默返回空列表） | SPEC-ORDER-QUERY-01 |
| `min_amount` 按"大于等于"语义过滤 | SPEC-ORDER-QUERY-02 |
| `min_amount == 0` 等价于不过滤 | SPEC-ORDER-QUERY-02 |
| `min_amount < 0` 必须抛 `InvalidFilterError` | SPEC-ORDER-QUERY-02 |
| 状态与金额两个条件之间是"与"关系 | SPEC-ORDER-QUERY-05 |

### 必须保持的既有行为（回归保护）

| 既有行为 | 来源规格 |
| --- | --- |
| 筛选结果保持入参顺序，不重排、不去重 | SPEC-ORDER-QUERY-03 |
| 空输入返回空列表且不抛异常 | SPEC-ORDER-QUERY-04 |
| 不带过滤条件时返回全部订单；查询不修改调用方传入的序列 | SPEC-ORDER-QUERY-03 / 04 |
| 结算模块（金额、折扣、税额、舍入）行为完全不变 | SPEC-PRICING-01 / 02 / 03 |

## 5. 操作步骤

```bash
# 0) 准备环境（详见 RUNBOOK.md）
export PYTHONPATH="$PWD/minimax"
export SDD_SEEKDB_HOST=127.0.0.1 SDD_SEEKDB_PORT=10100 SDD_SEEKDB_USER=root
export SDD_POWERCONTEXT_URL=http://127.0.0.1:8100
export MINIMAX_API_KEY=<你的 MiniMax API Key>          # 或依赖本机运行时回落
export MINIMAX_BASE_URL=https://api.minimaxi.com/anthropic/v1
export MINIMAX_MODEL=MiniMax-M2.1

# 1) 依赖自检（seekdb / PowerContext / MiniMax 三项都要 ok）
python -m sdd_context doctor

# 2) 导入工程资料到 seekdb（幂等）
python -m sdd_context import --project minimax/demo

# 3) 检索并输出开发上下文（人工核对 §4 的来源清单）
python -m sdd_context context \
  --task minimax/demo/tasks/TASK-001-status-filter.md \
  --output minimax/evidence/context.md

# 4) 完整流水线：导入 → 上下文 → MiniMax 改码 → 测试 → 状态写回
python -m sdd_context run \
  --task minimax/demo/tasks/TASK-001-status-filter.md \
  --project minimax/demo

# 5) 业务工程测试（与流水线里跑的是同一组用例）
cd minimax/demo && python -m pytest tests -v && cd ../..

# 6) 模拟"重启上下文模块"后读回状态（全新进程）
python -m sdd_context state load --task TASK-001
```

## 7. 重置方法

### 7.1 重置任务状态（回到"空状态"）

```bash
# 方式 A：换到一个新的 scope（PowerContext 里的全新空间，状态为空）
python -m sdd_context state reset --task TASK-001 --epoch 2
# 后续运行用新的 scope：
export SDD_POWERCONTEXT_SCOPE_KEY=TASK-001-reset-2

# 方式 B：彻底清空 PowerContext 数据（最接近"从未运行过"）
#   1) 停掉 powercontext server run
#   2) 删除 $POWERCONTEXT_HOME/powercontext.db
#   3) 重启 powercontext server run
```

### 7.2 重置工程资料（让数据库回到初始状态）

```bash
# 删除模块使用的库后重新导入
mysql -h 127.0.0.1 -P 10100 -u root -e "DROP DATABASE IF EXISTS sdd_context;"
python -m sdd_context import --project minimax/demo
```

### 7.3 重置代码（回到修改前状态）

```bash
cd minimax/demo
git checkout -- src/fulfillment/query.py     # 或用 evidence/diff/*.before 覆盖
```
